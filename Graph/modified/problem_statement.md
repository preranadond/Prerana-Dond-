## Modified Problem Statement -

A. Modify the program to accept a different starting vertex and display the traversal order.B. Modify the program to display the vertices reachable from the start and identify unvisited vertices.C. Modify the program to count reachable vertices or display their BFS levels. 

## Objectives

• Dynamic Traversals: Allow the user to input any valid starting department dynamically to generate its unique traversal sequence.

• Reachability & State Analysis: Partition the hospital departments cleanly into two specific lists: Reachable (visited) and Unvisited (isolated/unreachable) units.

• Distance Tracking (BFS Levels): Calculate and display the exact structural depth (BFS level) of each reachable department, indicating the minimum number of corridors needed to travel from the starting point.
