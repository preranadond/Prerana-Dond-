## Original Problem Statement - 

Develop a C++ program to represent hospital departments as vertices and corridors as edges. Apply BFS from a selected department and display all reachable departments in traversal order. Allow the user to select another department and check whether it is reachable from the starting department.


## Objectives

• Graph Representation: Model a hospital's layout by representing departments as vertices (nodes) and corridors as edges (connections).

• Graph Traversal: Implement Breadth-First Search (BFS) to traverse the hospital layout starting from a designated department.

• Reachability Verification: Determine and display all departments accessible from the starting point, and allow users to query whether a specific second department can be reached from the first.
